1. System Overview

My Tuition Center is a headless LMS (Learning Management System) consisting of two main parts:

ComponentURLPurpose
Client Websitemytuitioncenter.pkPublic-facing site built with Astro. Shows courses, tutors, about, contact, enrollment forms. Hosted on Vercel.
WordPress Backendcms.mytuitioncenter.pkContent management system. Admins manage courses, tutors, enrollments, classes. Hosted on your web server.

How they work together

  1. Admin adds content in WordPress (courses, tutors, classes)
  2. Auto-Deploy triggers — Vercel rebuilds the client website automatically
  3. Client website updates — courses and tutors appear live on mytuitioncenter.pk
Key benefit: Edit content in WordPress, and it automatically goes live on the public website within 1–2 minutes. No manual deployment needed.

3. WordPress Admin Backend (cms.mytuitioncenter.pk)

This is where administrators manage all content. Access via cms.mytuitioncenter.pk/wp-admin.

3.1 Managing Courses

  1. Go to Courses → Add New (or edit an existing course)
  2. Enter Title — e.g. "Cambridge O-Level Mathematics (Syllabus D)"
  3. Write Description in the editor (full course details)
  4. Set Featured Image — this shows as the course card image on the website
  5. Fill in the Course Details meta box (below the editor):
    • Price — e.g. "PKR 15,000/mo"
    • Subject Tag — e.g. "Mathematics" (used for filtering)
    • Grade Level — Primary, Lower Secondary, Upper Secondary, or A-Level
    • Format — "Online via Zoom", "In-Person", "Hybrid"
    • Tutor Name — the tutor teaching this course
    • Rating — e.g. "★★★★★" (stars)
    • Tag — e.g. "Course", "Program", "Workshop"
  6. Click Publish
Tip: The Subject Tag field controls which category the course appears under on the website (Mathematics, Physics, English, etc.). Use consistent names across courses.

3.2 Managing Tutors

  1. Go to Tutors → Add New
  2. Enter Title — the tutor's full name
  3. Write Bio in the editor
  4. Set Featured Image — profile photo
  5. Fill in the Tutor Details meta box:
    • Subject — e.g. "Advanced Mathematics & Statistics"
    • Badges — comma-separated list, e.g. "A-Level,O-Level Math,ECAT"
  6. Click Publish

3.3 Managing Enrollments

  1. Go to Enrollments in the admin menu
  2. View all enrollment requests submitted by students
  3. Edit enrollment to Publish it when payment is verified — this approves the enrollment
  4. When published, the student gains access to course materials in their dashboard

3.4 Managing Classes (Recorded & Live)

  1. Go to Recorded Classes or Live Classes
  2. Add Title, set the Course (via custom field), and provide the video URL
  3. For recorded classes: add the YouTube ID in the custom field
  4. For live classes: add the Live Session URL in the custom field
  5. Publish — students enrolled in the associated course will see it in their dashboard

3.5 Managing Tutor Applications

When a tutor applies via the website (with 10K PKR receipt upload):

  1. A Tutor Application post is created as draft
  2. A user account with Pending Tutor role is created
  3. Go to Users and change the role to Tutor to approve
  4. The tutor receives an email with login credentials and is redirected to their portal

How to Submit a Class

  1. Log in to your tutor account at cms.mytuitioncenter.pk/tutors
  2. Scroll to the Submit a Class section
  3. Select the Course from the dropdown
  4. Choose Class Type (Recorded Video or Live Session)
  5. Enter Class Title and YouTube ID (for recorded) or Session URL (for live)
  6. Click Submit — class is saved and appears in student dashboards

Tutor Application (New Tutors)

  1. Go to cms.mytuitioncenter.pk/tutors and scroll to the application form
  2. Fill in your details (name, email, phone, subjects)
  3. Upload the 10,000 PKR application fee receipt
  4. Submit — your application is sent to the admin for review
  5. Once approved, you'll receive an email with login credentials

  1. Log in at cms.mytuitioncenter.pk/auth with your student credentials
  2. You'll be redirected to your Student Dashboard
  3. View your enrolled courses under My Enrollments
  4. Watch recorded classes and mark them complete to track progress

How to Request a Refund

  1. Go to My Enrollments on the dashboard
  2. If eligible (within 30 days and less than 25% complete), click Request Refund
  3. Confirm the action — your enrollment will be cancelled and refund processed
Note: Refunds are only available within 30 days of enrollment and if you've completed less than 25% of the course.

Account Freeze

Freezing your account pauses your courses so you don't lose paid time. To unfreeze, simply click the button again.

7. Financial Escrow System

The escrow system ensures fair payments for both tutors and the platform.

How It Works

  1. Student enrolls in a course and submits payment receipt
  2. Admin approves enrollment (changes status to Published)
  3. Funds held in escrow — 75% reserved for tutor, 25% platform fee
  4. 30-day waiting period — student can request a refund during this time
  5. Release funds — admin releases payout to tutor after 30 days (or manually via Escrow Dashboard)

Access the Escrow Dashboard

WordPress Admin → Enrollments → Financial Escrow (submenu)

Magic Link Login

Users can log in without a password by requesting a magic link sent to their email. Click the link in the email to be automatically logged in and redirected to the correct dashboard.

Device Verification

Student accounts are locked to a specific device. If a login is detected from an unrecognised device, the session is blocked and the user is logged out for security.

Account Freeze

Both students and tutors can freeze their accounts. Frozen accounts cannot access course content, and the freeze pauses any active time-based commitments.

9. Auto-Deploy & Content Publishing

How Content Goes Live

  1. Edit content in WordPress (add/update/delete courses, tutors)
  2. Auto-Deploy triggers — the Vercel Deploy Hook fires automatically
  3. Vercel rebuilds the client website (takes ~1–2 minutes)
  4. Site updates — changes appear live on mytuitioncenter.pk

Setting Up Auto-Deploy

  1. In Vercel Dashboard → Settings → Git → Deploy Hooks, create a hook named "WordPress CMS"
  2. Copy the generated URL
  3. In WordPress → Settings → Auto Deploy, paste the URL and save
Tip: Auto-Deploy triggers for ALL changes to courses and tutors (add, update, delete, trash). No manual redeployment needed.
